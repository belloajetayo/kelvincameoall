## 🏛️ About Kelvin Cameo

**Kelvin Cameo (RC: 1613032)** is a diversified indigenous Nigerian enterprise headquartered along the Abuja–Kaduna Capital Corridor in Suleja, Niger State. 

The group operates scalable market leaders across four pillar economic sectors:
1. **Kelvin Cameo Energy** — Modern retail fuel dispensing (PMS, AGO, DPK), 50-tonne LPG cooking gas skids, lubricants, and solar microgrid installations.
2. **Kelvin Cameo Real Estate** — Master-planned residential communities, verified title acquisitions (C of O / Gazette), and commercial highway filling station plots.
3. **Kelvin Cameo Agriculture** — 2,500+ hectares of mechanized grains (maize, soybean), 50,000+ commercial layer poultry, beef feedlots, 10,000 MT silos, and smallholder outgrower partnerships.
4. **Kelvin Cameo Resort Hotel** — Premier hospitality destination featuring 10 authentic luxury room/suite classes, 1,000-seat grand banquet auditorium, swimming pool, billiards lounge, and executive conference facilities.

## 🚀 Getting Started

### Local Development / Preview
Simply open `index.html` in any modern browser:
```bash
# Clone the repository
git clone https://github.com/belloajetayo/kelvincameoall.git

# Navigate into project directory
cd kelvincameoall

# Open index.html in default browser (Windows PowerShell)
Start-Process index.html
```

### Deploying to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch` -> choose `main` / `root` -> click **Save**.
4. Your website will be live at `https://belloajetayo.github.io/kelvincameoall/` within seconds!
